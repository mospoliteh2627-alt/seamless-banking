# Что показывать на защите

## 1. Web → Mobile

1. `http://127.0.0.1:8787` → вход `0000`.
2. «Новый перевод» → получатель → сумма.
3. «Продолжить на телефоне»: показать QR, код, **timeline**.
4. `http://127.0.0.1:8787/m` → QR/код → **анимированный Face ID** → PIN `0000`.
5. Показать восстановленный шаг, фокус и сумму.
6. На вебе — баннер «Время перехода: X с».

## 2. Mobile → Web

1. На телефоне «Новый перевод» → заполнить → сохранить.
2. На веб-клиенте открыть «Незавершённые операции» → тот же черновик.

## 3. Процесс и SLA

- На мобильном главном: стадия, прогресс, риск, SLA.
- На веб-форме: timeline процесса и SLA.
- В `/admin` (код `ADMIN-2026`): канбан и аудит.

## 4. Метрики

- CRR = 100 %.
- p95 синхронизации = 15 мс.
- повторный redeem → 409.
- запись с веба при lease → `LEASE_HELD`.
- 3 E2E-теста, 2 Flutter-теста.

## 5. Ограничения

- демо-step-up, не реальная биометрия;
- нативные Android/iOS не собраны;
- полевого SUS/CES нет.
