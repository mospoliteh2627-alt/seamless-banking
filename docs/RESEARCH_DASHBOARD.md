# Исследовательская панель (research mode)

Страница `/research` связывает интерфейс с диссертацией: показывает гипотезы,
метрики, результаты имитации и позволяет провести собственное измерение.

## 1. Что видно

| Блок | Содержание |
|---|---|
| KPI | TCT для A/B/C, эффект −38,0 %, d_z = 2,92 |
| График | сравнение времени выполнения по трём условиям |
| Гипотезы H1–H6 | критерий, результат, статус (подтверждена / не проверена / сценарно) |
| Метрики M1–M38 | выборочно: TCT, p95, CRR, WCAG, конверсия, SI |
| Агрегаты | средние по сохранённым сессиям |
| Сессии | последние измерения: условие, TCT, SUS, CES |
| Методика | 48 профилей, 3 условия, 120 повторов, парный тест |

## 2. Действия

- **Таймер**: старт/стоп, фиксация времени с точностью 0,1 с.
- **Сохранение сессии**: условие A/B/C, ошибки, завершённость, SUS, CES, участник.
- **Экспорт CSV**: собственные сессии.
- **Переход к измерению** из hero-блока.

## 3. API

| Метод | Путь | Назначение |
|---|---|---|
| GET | `/v1/research/overview` | гипотезы, метрики, имитация, агрегаты |
| GET | `/v1/research/sessions` | сессии текущего пользователя |
| POST | `/v1/research/sessions` | сохранить измерение |
| GET | `/v1/admin/research` | все сессии (admin/analyst/support) |
| GET | `/v1/admin/export?type=research&format=csv` | выгрузка |

Пример:

```json
{
  "condition": "A",
  "tctSec": 276.5,
  "errors": 0,
  "completed": true,
  "sus": 84,
  "ces": 2.1,
  "participant": "P-001"
}
```

## 4. Валидация

- условие — только A/B/C;
- TCT — 1…3600 с;
- ошибки — 0…50;
- SUS — 0…100, CES — 1…7;
- каждое сохранение попадает в аудит (`research.session_saved`).

## 5. Ограничения

- Это демонстрационный сбор данных, а не замена полевому эксперименту.
- SUS/CES вводятся вручную; в пилоте — валидированные шкалы и информированное согласие.
- Агрегаты по малым выборкам нестабильны; для H3/H4 нужен этап с 48–56 участниками.
