# Аудит доступности (WCAG 2.2 AA)

Дата: 19.10.2026. Инструмент: axe-core 4.14.0 + Playwright/WebKit.
Скрипт: `scripts/a11y-audit.mjs`. Проверялись теги `wcag2a`, `wcag2aa`, `wcag21a`,
`wcag21aa`, `wcag22aa`.

## 1. Результат

| Экран | Нарушения |
|---|---|
| Дашборд интернет-банка | 0 |
| Панель доступности | 0 |
| Форма перевода | 0 |
| QR-модальное окно | 0 |
| Мобильный черновик | 0 |
| Админ-панель | 0 |
| Панель исследования | 0 |

Итого: **0 нарушений уровня A/AA**, 0 serious/critical.

## 2. Что было исправлено

| Нарушение | Элемент | Исправление |
|---|---|---|
| `color-contrast` | кнопка «Новый перевод» | accent `#2F6BFF` → `#1F57E0` (контраст белого ≥ 4,5:1) |
| `color-contrast` | бейдж `online` | текст `#0B8F78` → `#076B5A`, фон усилен |
| `label-content-name-mismatch` | логотип | `aria-label` приведён к видимому «Векторбанк» |
| `color-contrast` | мобильный статус | `muted` `#6B7A90` → `#4D5C70` |
| `color-contrast` | «Черновик восстановлен» | `#0B7F6B` → `#065F4F` |

## 3. Проверенные сценарии

1. **Клавиатура.** Tab/Shift+Tab по дашборду, форме, модальным окнам; Escape закрывает
   модальное окно; focus trap удерживает фокус внутри диалога; возврат фокуса на кнопку.
2. **Экранный диктор.** Семантика полей (`label`), `aria-live` для статуса сохранения,
   `role="dialog"` + `aria-modal` + `aria-labelledby`, альтернативный текст QR.
3. **Масштабирование.** Профиль 115 % и 130 % переносится из web в mobile вместе с
   черновиком; проверено на mobile-стенде.
4. **Контраст.** Профиль «повышенный контраст» усиливает `muted`, `line`, границы полей.
5. **Анимация.** `prefers-reduced-motion` и переключатель «уменьшить анимацию» отключают
   переходы и пульсацию.

## 4. Ограничения

- Автоматический аудит не заменяет ручную проверку с NVDA/VoiceOver и реальными
  пользователями с инвалидностью.
- Flutter web-сборка компилируется, но нативные жесты iOS/Android и динамический
  тип на устройстве не проверялись (нет эмулятора/устройства).
- Контраст проверен для текущей палитры; при смене темы требуется повторный прогон.

## 5. Связь с метриками

| Метрика | Значение |
