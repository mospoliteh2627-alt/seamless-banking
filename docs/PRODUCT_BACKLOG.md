# Продуктовый бэклог и стресс-тест функций

Проект: платформа бесшовного перехода (Seamless Handoff) для банковских интерфейсов.
Роль: ИТ-архитектор / Technical Product Manager.
Аудитория: B2C-клиенты банка (основная), B2B-команды банка — продукт, UX, ИБ, поддержка
(заказчик и эксплуатация), внутренние аналитики (третичная).
Стек: Fastify 5 + Redis 7 + WebSocket + PWA + Flutter 3 + OpenAPI 3.1 + Docker.
Горизонт: 3–6 месяцев силами одного разработчика; всё, что не влезает, переводится
в MVP-аналог или в дорожную карту.

Статус: F1, F2, F6, F12, F13, F18, F26 уже реализованы в демо-контуре;
остальные — проектные требования и дорожная карта.

Обозначения сложности: **Low** — до 1 недели, **Medium** — 2–4 недели,
**High** — больше месяца или требует внешней инфраструктуры.
Приоритеты: **P0** — без этого нет продукта, **P1** — пилот с банком,
**P2** — развитие после пилота.

## 3. Сводный вердикт

**Go (17):** F1, F2, F3, F6, F7, F8, F10, F12, F13, F17, F18, F19, F21, F22, F23, F24, F26.
**Conditional (6):** F4, F9, F11, F14, F16, F25 — только с MVP-упрощением.
**No-Go для соло (3):** F5, F15, F20 — переносятся в дорожную карту после пилота.

Критические выводы:

1. **Нельзя тащить всё в диссертацию.** Научное ядро — F1, F2, F6, F13, F24, F26.
   Остальное — продуктовая обвязка, которая усиливает практическую значимость, но
   не должна увеличивать объём главы 3.
2. **RBAC и аудит — минимально необходимые B2B-функции.** Без них банк не выведет
   прототип даже в пилот, поэтому F12/F13 имеют приоритет P0/P1.
3. **ML-скоринг (F9) без данных — риск.** На демо-данных допустим только прозрачный
   логистический скоринг с явными признаками; выдавать его за промышленную модель
   нельзя.
4. **Дублирование устранено:** F7 (воронка) vs F8 (SLO) vs F11 (когорты) — разные
   уровни; F12 (роль) vs F14 (атрибуты) vs F15 (аутентификация) — разные контуры;
   F17 (вебхук) vs F21 (уведомление) — разные получатели.
5. **Архитектурный минимум для пилота:** PostgreSQL (операции/аудит), Redis
   (черновики/очереди), Keycloak (OIDC), S3-совместимое хранилище (экспорт),
   Prometheus/Grafana (SLO). Kafka/ClickHouse — только при росте нагрузки.
